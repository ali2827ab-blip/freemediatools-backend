# FreeMediaTools downloader backend

This repository contains the backend for FreeMediaTools: a Flask app that proxies video downloads (yt-dlp) and calls AssemblyAI for transcription.

## Setup

```bash
pip install -r requirements.txt
python app.py
```

Deployed on Render.
